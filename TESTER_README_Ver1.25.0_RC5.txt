ポケヨヤ君 User Edition Ver.1.25.0 RC5 テスター向け案内

【重要】
このSetup.exeは正式版ではありません。機能確認を目的としたRC5テスト版です。
RC4以前のSetup.exeではなく、RC5 Setup.exeを使用してください。

【セットアップ】
1. 既存のRC4以前をWindowsからアンインストールします。
2. PokeyoyaKun_User_Setup_Ver1.25.0_RC5.exeを実行します。
3. 「ポケヨヤ君」を起動し、接続テストが成功することを確認します。
4. 管理者から案内されたオンラインライセンスコードで認証します。

【3か月無料ライセンス】
テスター向け3か月無料ライセンスは管理者が手動で発行します。
アプリからライセンスを新規発行することはできません。

【RC5で確認していただきたい機能】
・初回セットアップ後にホーム画面が表示されること
・かんたんモード／詳細モードを切り替えて再起動後も保持されること
・ホーム、設定、横断検索が小さい画面でも操作できること
・処理中表示、成功・警告・エラー、キーボードフォーカスが確認できること
・Windows 10でライセンス接続テストが証明書エラーにならないこと
・有効なオンラインライセンスで認証できること
・Feedback投稿と受付状態確認が成功すること
・人気要望・開発状況を取得できること
・遊戯王OCGの商品表示、公式取得、Gmail判定

【不具合報告】
サイドバーの「ご意見・ご要望」で「不具合」を選択してください。
個人情報、ライセンスキー、認証トークン、端末コードは記載しないでください。

【配布ファイルの確認】
SHA256SUMS.txtに記載されたSHA-256とSetup.exeのハッシュが一致することを
確認してください。不一致の場合は実行せず、管理者へ連絡してください。
