ポケヨヤ君 User Edition Ver.1.25.0 RC3

本リリースはテスター向け評価版であり、正式版ではありません。
利用には管理者が発行するオンラインライセンスコードが必要です。

RC3の重要な修正
- PyInstaller版でHTTPS CA証明書が通信に使われない問題を修正
- certifiのCAバンドルを明示した共通SSLContextへ統一
- ライセンス接続テスト、認証POST、Feedback、Roadmapへ共通TLS処理を適用
- ホスト名検証とCERT_REQUIREDを常に有効化
- CAバンドル欠損・読込失敗時は通信を拒否
- PyInstallerとNuitkaへcertifiデータ同梱を明示
- frozen EXEがCAバンドルを読み込める自己診断を追加

RC2から継続する機能
- 遊戯王OCGカテゴリ、商品一覧、商品詳細、新弾候補
- 遊戯王OCG公式サイトの商品情報取得
- Gmail抽選結果の遊戯王分類と人気要望の遊戯王表示
- 遊戯王対応店舗情報とポケモンへの誤分類防止

RC1から継続する機能
- 本番HTTPS固定のオンラインライセンス、Feedback、Roadmap API
- HTTP、別ホスト、別ポートへのリダイレクト拒否
- ご意見・ご要望、店舗追加依頼、受付状態確認
- RoadmapのETag／304、5分キャッシュ、オフライン表示
- 秘密情報検査、配布物監査、実行ファイル整合性検査

テスター向け注意事項
- RC2 Setup.exeは公開せず、RC3 Setup.exeを使用してください。
- RC3は予期しない不具合を含む可能性があります。
- 不具合はアプリの「ご意見・ご要望」から報告してください。
- 個人情報、ライセンスキー、認証トークン、端末コードを本文へ記載しないでください。
- 3か月無料ライセンスは管理者がテスターごとに手動発行します。
