ポケヨヤ君 User Edition Ver.1.25.0 RC4

本リリースはテスター向け評価版であり、正式版ではありません。
利用には管理者が発行するオンラインライセンスコードが必要です。

RC4の重要な修正
- User Editionのオンラインライセンス接続先を本番APIへ変更
  https://api.pokeyoyakun.com
- 配布版は古いonline_license_settings.jsonのserver_urlを使用せず、
  EXEへ同梱した本番接続先を優先
- activate、verify、deactivateの固定APIパスを検査
- DNS、TLS証明書、HTTPステータス、タイムアウトを区別するエラー表示へ改善
- エラー表示へ接続先URLを追加し、ライセンスキー全文は表示しない
- PyInstaller／Nuitkaのビルド開始前に本番接続先を検証

RC3から継続する機能
- certifi CAによるTLS証明書とホスト名の検証
- 別ホスト、平文HTTP、443以外へのリダイレクト拒否
- 遊戯王OCGの商品情報取得
- GitHub Releasesを利用したUser Edition自動アップデート
- 秘密情報検査、配布物監査、実行ファイル整合性検査

テスター向け注意事項
- RC4は予期しない不具合を含む可能性があります。
- 3か月無料ライセンスは管理者がテスターごとに手動発行します。
- 個人情報、ライセンスキー、認証トークン、端末コードを報告へ記載しないでください。
