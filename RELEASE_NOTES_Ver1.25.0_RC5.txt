ポケヨヤ君 User Edition Ver.1.25.0 RC5

本リリースはテスター向け評価版であり、正式版ではありません。
利用には管理者が発行するオンラインライセンスコードが必要です。

RC5の主な変更
- 左サイドメニューを一般利用者向けに整理
- かんたんモード／詳細モードと設定保存に対応
- 今日やることを中心としたホームダッシュボードへ刷新
- 設定カテゴリ、設定内検索、未保存・保存結果表示を改善
- 商品、応募、店舗、通知、公式情報、お気に入りの横断検索を追加
- 初回セットアップウィザードを追加
- 余白、カード、ボタン、フォーカス、ダークテーマを全画面で統一
- 小画面、高DPI、処理中表示、二重クリック防止を改善

RC3から継続するセキュリティ修正
- certifiのCAバンドルを明示した共通SSLContext
- ライセンス、Feedback、RoadmapのTLS証明書検証
- CAバンドル欠損時のフェイルクローズ
- frozen EXEのCAバンドル自己診断

RC2から継続する機能
- 遊戯王OCGカテゴリ、商品一覧、商品詳細、新弾候補
- 遊戯王OCG公式サイトの商品情報取得
- Gmail抽選結果の遊戯王分類と人気要望の遊戯王表示
- 遊戯王対応店舗情報とポケモンへの誤分類防止

RC1から継続する機能
- 本番HTTPS固定のオンラインライセンス、Feedback、Roadmap API
- HTTP、別ホスト、別ポートへのリダイレクト拒否
- ご意見・ご要望、店舗追加依頼、受付状態確認
- RoadmapのETag／304、5分キャッシュ、オフライン表示
- 秘密情報検査、配布物監査、実行ファイル整合性検査

テスター向け注意事項
- RC4以前のSetup.exeは公開せず、RC5 Setup.exeを使用してください。
- RC5は予期しない不具合を含む可能性があります。
- RC5の実行ファイルとインストーラーにはAuthenticodeコード署名がありません。
- Windows SmartScreen / Smart App Controlで警告または実行ブロックが表示される可能性があります。
- 正式版までにコード署名へ対応する予定です。Windowsのセキュリティ設定を回避・無効化しないでください。
- 不具合はアプリの「ご意見・ご要望」から報告してください。
- 個人情報、ライセンスキー、認証トークン、端末コードを本文へ記載しないでください。
- 3か月無料ライセンスは管理者がテスターごとに手動発行します。
