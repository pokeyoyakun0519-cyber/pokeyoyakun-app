ポケヨヤ君 使用方法

【初期設定】
1. ライセンス認証
2. Discord Webhook URL またはメール通知設定
3. 監視間隔の設定
4. 自動監視をON

【公式情報ソース】
・公式サイトを登録
・「登録ページを手動確認」を押す
・発売予定商品が自動で商品一覧へ追加されます

【商品一覧】
・予約したい商品を確認
・サイトごとの予約ページを開く

【通知】
・Discord
・メール
・通知センターで履歴確認

【バックアップ】
・バックアップ画面から作成
・ZIP出力・復元が可能

【サポート】
・サポートZIPを作成するとログや設定情報をまとめて出力できます。


【ポケモンカード公式の商品取得】
公式情報ソースに https://www.pokemon-card.com/ を登録し、
「登録ページを手動確認」を押してください。
トップページの商品バナーから商品詳細ページをたどり、
正式な商品名と発売日を商品一覧へ自動追加します。


【新弾候補から販売情報を検索】
公式情報ソースを手動確認すると、商品名と発売日が新弾候補へ入ります。
新弾候補の「販売・抽選情報を検索」を押してください。
ポケモンセンターオンラインまたはヨドバシで一致する情報が見つかった時だけ、商品一覧へ追加されます。


【応募・抽選結果の管理】
1. 商品一覧で店舗の応募ページを開きます。
2. 応募完了後「応募・予約受付完了」にチェックします。
3. 結果発表日までは「抽選受付完了」と表示されます。
4. 結果日以降は「抽選結果確認」と表示され、Discordにも通知されます。
5. アプリや会員ページで結果を確認し、「当選」または「落選」を選びます。


【応募ダッシュボード】
左メニューの「応募ダッシュボード」を開くと、未応募・応募済み・結果確認・当選・落選をまとめて確認できます。
結果確認日が来た抽選は上に表示されます。確認ページを開いて結果を確認後、当選または落選を登録してください。


【Ver.1.5.0の使い方】
ホーム画面の「今日・明日の予定」で、応募締切・結果確認・購入期限・発売日を確認できます。
応募ダッシュボードでは状態フィルター、並び順、商品名・店舗名検索を利用できます。
自動監視画面では「新弾候補の販売・抽選情報を自動検索」を有効にし、再検索間隔を設定してください。


【全候補の販売情報検索】
候補数や店舗数によっては5～20分以上かかる場合があります。
確認画面で「検索開始」を押すとバックグラウンド検索が始まります。


【応募後の流れ】
応募ダッシュボードで「応募済みにする」を押すと、抽選結果確認画面へ移動します。結果発表後に公式ページを開き、当選・落選を確認してください。


【リリース前の確認】
配布版を作るときはFULL_RELEASE_TEST.batを実行してください。
Release Check、ソース起動、EXE作成、EXE起動、インストーラー、配布パッケージの順に確認されます。


【店舗JSONプラグインの追加】
1. プラグイン管理を開きます。
2. 「サンプルJSONを作成」を押します。
3. 「JSONプラグインフォルダーを開く」を押します。
4. サンプルを複製して店舗名・URL・TCGを編集します。
5. 再スキャン後、販売情報検索へ反映されます。


【店舗プラグインの削除・無効化】
組み込み店舗は「無効化」、外部JSON店舗は「無効化」または「削除」が使えます。
削除しても応募履歴や過去の抽選結果は残ります。

【メールアカウント】
左メニューのメールアカウントから最大3件まで登録できます。
パスワードは入力・保存しません。Gmail OAuth連携は今後の版で有効化します。


【Gmailから抽選結果を確認】
1. GMAIL連携設定手順.txtに従ってOAuth設定を行います。
2. メールアカウント画面でGmailと連携します。
3. 「このメールを確認」または「連携済みメールをすべて確認」を押します。
4. 一致した当選・落選は応募ダッシュボードと抽選結果確認へ反映されます。
アプリ限定の抽選結果は従来どおり手動で確認してください。


【Gmail抽選結果の自動確認】
1. メールアカウント画面でGmail連携を完了します。
2. 自動監視画面でGmail自動確認をONにします。
3. 当選・落選・要確認の新着結果は通知センターとDiscordへ通知されます。
アプリ限定抽選は結果発表日に対象アプリを開いて手動確認してください。


【オンラインライセンスのローカル確認】
1. license_server/START_SERVER.batを実行します。
2. admin_cli.py issueでライセンスキーを発行します。
3. アプリのオンラインライセンス設定でサーバーを有効化します。
4. 次回起動時に発行されたキーを入力します。
公開運用時はHTTPSと強力な管理者トークンが必須です。


【ワンクリックアップデート】
1. アップデート画面でマニフェストURLを設定します。
2. 更新を確認します。
3. 新しい版がある場合はワンクリック更新を押します。
4. ダウンロードと検証後、アプリが終了して更新・再起動します。
更新失敗時は旧バージョンへ自動復元します。


【オンラインプラグイン配信】
1. plugin_server/START_SERVER.batを起動します。
2. publish_cli.pyで店舗JSONを公開します。
3. アプリのプラグイン配信画面でマニフェストURLを設定します。
4. 更新確認後、すべてインストールを押します。
5. プラグイン管理で再スキャンすると店舗が反映されます。


【統合Web管理画面】
1. admin_server/START_ADMIN_SERVER.bat内のパスワードを変更します。
2. バッチを起動します。
3. http://127.0.0.1:8790 をブラウザで開きます。
4. ログイン後、ライセンス・プラグイン・更新を管理できます。
外部公開はせず、当面はLAN内だけで使用してください。


【管理サーバー初回設定】
1. admin_server/START_ADMIN_SERVER.batを実行します。
2. 管理者パスワードを2回入力します。
3. このPCだけなら127.0.0.1、LAN内利用なら0.0.0.0を選びます。
4. 完了後、管理画面がブラウザーで自動的に開きます。


【管理画面の運用機能】
ライセンス画面ではキー・利用者名・状態・期限で絞り込めます。
CSV出力で一覧を保存できます。
自己診断ではDB、配信、ディスク、バックアップを確認できます。
操作ログでは主要な管理操作の履歴を確認できます。


【自動メンテナンス】
管理画面の設定から、自動バックアップ、実行間隔、保持世代数、ディスク警告値を変更できます。
「今すぐメンテナンス実行」で動作確認できます。


【RCまとめ確認】
RC確認手順.txtに従って、アプリ本体と管理サーバーをまとめて確認してください。
