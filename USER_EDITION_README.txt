【ポケヨヤ君 User Edition Ver.1.25.0 RC2】

本製品はテスター向けの評価版です。正式版ではありません。
予期しない停止や表示不具合が発生する可能性があるため、重要な用途へは
使用せず、必要なデータは事前にバックアップしてください。

【テストライセンス】
RC2テスター向けの3か月無料ライセンスは、管理者が手動で発行します。
アプリやインストーラーにライセンス発行機能・秘密鍵は含まれていません。
管理者から案内されたオンラインキーを初回起動時に入力してください。

【主なテスト対象】
・固定HTTPSライセンスAPIによるオンライン認証
・「ご意見・ご要望」からの質問、不具合、機能要望の送信
・店舗追加依頼と受付番号・受付状態の確認
・「人気要望・開発状況」の一覧、TCG／状態フィルター、詳細表示
・Roadmap APIのETag、5分キャッシュ、オフライン時の直近表示
・遊戯王OCGの商品一覧、商品詳細、新弾候補、人気要望の表示
・遊戯王OCG公式の商品情報取得とGmail抽選結果判定
・遊戯王商品をポケモンへ誤分類しないこと

【不具合報告】
アプリのサイドバーにある「ご意見・ご要望」から「不具合」を選んで
報告してください。氏名・住所など不要な個人情報、ライセンスキー、
認証トークン、端末コードは本文へ記載しないでください。

【本番接続先】
ライセンスAPI、Feedback API、Roadmap APIはすべて次の固定HTTPSホストを
使用します。
https://pokeyoyakun.duckdns.org

平文HTTP、IPアドレス、443以外のポート、別ホスト・別ポートへの
リダイレクトは拒否します。任意URLを指定する利用者向け経路はありません。

【配布セキュリティ】
管理サーバー、ライセンス発行CLI、秘密鍵、管理者トークン、Stripe秘密鍵、
DB認証情報、テスト、Pythonソース、デバッグ情報、実ユーザー設定、
ライセンスキャッシュ、DPAPI由来ファイルは配布物へ含めません。
ライセンスの発行、停止、期限、端末数の最終判定はサーバー側で行います。

【インストール先と利用者データ】
インストール先: %LOCALAPPDATA%\Programs\PokeyoyaKun
設定・ログ・登録済みオンラインキー: %LOCALAPPDATA%\PokeyoyaKun
通常は管理者権限を必要としません。

【セキュリティ上残る限界】
・利用者PC上で動くコードは解析や実行時パッチを完全には防げません。
・サーバーURLはバイナリや通信先から判別でき、非表示は秘密化ではありません。
・SHA-256マニフェストは単純な破損・差し替え検知です。EXEとマニフェストを
  同時に変更する攻撃には、将来Windows Authenticode署名が必要です。
・端末コードや保存済みオンラインキーは利用者PCから読み取られる可能性が
  あるため、サーバー側の失効、端末数制限、レート制限、監査を併用します。

【ビルド方式】
今回のRC2 Setup.exeは既存互換のPyInstaller版です。比較用としてNuitkaの
ネイティブビルド構成も維持しています。
