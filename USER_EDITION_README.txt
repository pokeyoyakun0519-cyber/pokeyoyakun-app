【ポケヨヤ君 User Edition Ver.1.24.0 RC】

一般利用者向けの製品版ビルド一式です。
管理サーバー、ライセンス発行CLI、秘密鍵、管理者トークン、Stripe秘密鍵、
DB認証情報、テスト、Pythonソース、デバッグ情報は配布物へ含めません。

【オンラインライセンス認証】
初回起動時に、管理者から案内されたオンラインキーを入力します。
端末コードとキーを認証サーバーへ送信し、サーバーが返した判定結果だけで
起動可否を決定します。ローカルの認証キャッシュだけでは起動できません。
配布版ではサーバーURLを画面へ表示せず、設定ファイルでの差し替えも無視します。
URL変更欄はAPP_CHANNELがdevの開発者ビルドだけに表示されます。

【PyInstaller版（既存・比較用）】
1. BUILD_USER_EDITION.batを実行
2. release\user_distへ従来方式のonefile EXEを作成
3. Inno Setup 6があればUser Editionインストーラーも作成

【Nuitka版（推奨候補）】
1. BUILD_USER_EDITION_NUITKA.batを実行
2. release\user_dist_nuitkaへネイティブコンパイル済みEXEを作成

Nuitka版はライセンス通信モジュールを含むPythonモジュールをC/C++経由で
ネイティブコンパイルします。PyInstaller版は比較・切り戻し用として維持します。
初回NuitkaビルドはCコンパイラー等の取得に時間がかかる場合があります。

【ビルド時セキュリティ検査】
両ビルドは開始前に秘密鍵、Stripe秘密鍵、管理者トークン、DB URL等を検索します。
該当候補があればビルドを中止します。完成後も.py、.pyc、.pdb、.spec、tests、
管理サーバー等の混入を検査します。

配布フォルダーには各EXEのSHA-256を記録したrelease-integrity.jsonを生成します。
メインEXEと設定EXEは起動時に自身のハッシュと不要な開発用ファイルを検査します。
インストーラーにはこのマニフェストも必ず同梱します。

【インストール先と利用者データ】
インストール先: %LOCALAPPDATA%\Programs\PokeyoyaKun
設定・ログ・登録済みオンラインキー:
%LOCALAPPDATA%\PokeyoyaKun
管理者権限は不要です。

【セキュリティ上残る限界】
・利用者PC上で動くコードは、Nuitka化しても解析や実行時パッチを完全には防げません。
  最終判定とライセンス発行ロジックは必ずサーバー側だけに置いてください。
・サーバーURLはバイナリや通信先から判別できます。画面から隠すことは秘密化ではありません。
・SHA-256マニフェストは偶発破損や単純な差し替え検知です。攻撃者がEXEと
  マニフェストの両方を書き換える攻撃には、Windows Authenticode署名と
  安全な更新配信を追加する必要があります。
・現在の既定サーバーURLがHTTPの間は、中間者攻撃による応答改ざんを防げません。
  本番配布前に信頼できる証明書を持つHTTPSへ移行してください。
・端末コードや保存済みオンラインキーは利用者PCから読み取れます。
  サーバー側で端末数制限、失効、レート制限、監査ログを実施してください。
・オフライン起動を安全に再導入する場合は、サーバー秘密鍵で署名した短命トークンを使い、
  クライアントへ秘密鍵や共有HMAC鍵を置かないでください。
