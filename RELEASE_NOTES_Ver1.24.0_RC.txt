ポケヨヤ君 User Edition Ver.1.24.0 RC

主な変更
- 初回ライセンス認証画面からサーバーURL入力欄を削除
- 固定HTTPS接続先の /health を確認できる接続テストを追加
- User Editionのオンラインライセンスを初期状態で有効化
- 接続先をonline_license_endpoint.jsonの固定HTTPSホスト名へ統一
- 平文HTTP、IPアドレス、443以外の公開API接続を拒否
- HTTPS以外または別ホストへのリダイレクトを拒否
- 本番接続先を https://pokeyoyakun.duckdns.org に固定
- URL形式チェックと接続エラー表示を改善
- 不正な設定値やサーバー応答、オフライン期限処理を堅牢化
- 停止・期限切れなどサーバーの拒否時はオフライン認証へ移行しないよう修正
- アプリとインストーラーのバージョンを1.24.0 RCへ更新

設定保存先
%LOCALAPPDATA%\PokeyoyaKun\config\online_license_settings.json

外部接続確認
1. 管理PCでライセンスサーバーとHTTPSリバースプロキシを起動します。
2. User Editionを管理PCとは別の回線へ接続します。
3. 初回認証画面で「接続テスト」を実行します。
4. 成功後、オンラインキーを入力して認証します。

注意
User Editionは固定ホスト名のHTTPS（443）だけを使用します。
平文HTTP、IPアドレス、443以外のポート、別ホストへのリダイレクトは拒否します。
