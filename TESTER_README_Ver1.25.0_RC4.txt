ポケヨヤ君 User Edition Ver.1.25.0 RC4 テスター向け案内

【重要】
このSetup.exeは正式版ではありません。機能確認を目的としたRC4テスト版です。

【セットアップ】
1. 既存版を終了します。
2. PokeyoyaKun_User_Setup_Ver1.25.0_RC4.exeを実行します。
3. ポケヨヤ君を起動し、オンラインライセンス接続テストを実行します。
4. 接続先がhttps://api.pokeyoyakun.comで成功することを確認します。
5. 管理者から案内された3か月無料ライセンスで認証します。

【確認項目】
- activateによる初回認証
- 再起動後のverify
- 端末解除時のdeactivate
- 旧online_license_settings.jsonが残る環境でも本番APIが使われること
- DNS、TLS、HTTP、タイムアウトのエラー表示
- 自動アップデートのRC4現在バージョン判定

【不具合報告】
個人情報、ライセンスキー、認証トークン、端末コードは記載しないでください。
接続先URL、HTTPステータス、表示されたエラー分類だけを報告してください。
